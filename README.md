# Apoio Fortaleza

Projeto acadêmico desenvolvido em equipe durante o curso de Análise e Desenvolvimento de Sistemas (ADS).

## Objetivo

Desenvolver um site voltado ao acolhimento psicológico, facilitando o acesso a informações e serviços de apoio em Fortaleza.

## Funcionalidades

- Apresentação de informações sobre apoio psicológico.
- Acesso a recursos e serviços de apoio.
- Interface pensada para facilitar a navegação e a acessibilidade.

## Tecnologias utilizadas

Cursor Visual Studio
